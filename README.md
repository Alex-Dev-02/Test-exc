## Модуль "Форма задать вопрос"

Для работы с модулем, необходимо загрузить его к себе в проект в папку local/modules.

Далее необходимо установить модуль в админ панели Битрикс. Сделать это можно в следующем разделе админ панели: 

Marketplace->Установленные решения. Появится список, в котором отобразится наш модуль "Форма задать вопрос", его необходимо установить.

После установки нужно зайти в настройки модуля и прописать параметры для его использования.
Сделать это можно в следующем разделе:

Настройки->Настройки продукта->Настройки модулей->Веб-формы.

## Настройка модуля

Для корректной работы модуля нужно настроить 2 поля:
1. Webhook URL Bitrix24	- в данное поле необходимо записать веб хук.
2. ID целевой формы - нужно прописать id формы.

Модуль работает с веб-формами, которые можно создавать в следующем разделе:

Рабочий стол->Сервисы->Веб-формы.
